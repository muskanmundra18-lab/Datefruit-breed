# Date Fruit Classification using ANN

A supervised machine-learning project that uses an **Artificial Neural Network (ANN)** to classify date-fruit varieties from tabular features.

## Objective

The model learns patterns in measured date-fruit characteristics and predicts the corresponding fruit variety.

## Workflow

```text
Date Fruit Dataset
       ↓
Data Preprocessing
       ↓
Feature Preparation
       ↓
ANN
       ↓
Classification
       ↓
Evaluation
```
